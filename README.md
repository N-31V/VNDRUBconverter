# Currency Tracker

Flutter-приложение для сравнения стоимости оплаты во вьетнамских донгах
через Bybit QR, Т-Банк QR и перевод Т-Банка с курсами ЦБ РФ.
Основной целевой сценарий — Android; платформенные каталоги других систем
также есть в репозитории, но для Linux/Windows/Web хранилище требует адаптации.

## Данные и расчёты

- USD/RUB и VND/RUB: XML с `https://www.cbr-xml-daily.ru/daily_utf8.xml`.
- Перевод Т-Банка: публичный API, категория `DebitCardsTransfers`, пара RUB/VND,
  поле `buy` (VND за 1 RUB).
- Bybit QR: ручной ввод VND за 1 USDT.
- Т-Банк QR: ручной ввод рублей за 10 000 VND, внутри хранится VND за 1 RUB.
- Рублёвая стоимость USDT оценивается как USD/RUB ЦБ × 1.005.
  Это фиксированная надбавка 0,5%, а не фактический курс покупки USDT.

При запуске сначала показываются локальные значения. Затем источники обновляются
независимо, с тайм-аутом 15 секунд. Ошибка одного источника выводится отдельно;
сохранённые данные и расчёты остальных источников остаются доступны. Недоступные
значения обозначаются `—`.

В компактной таблице столбцы выравниваются по ширине фактических значений.
Строка `VND/RUB` показывает рубли за 10 000 VND, `к ЦБ %` — отклонение
стоимости от ЦБ со знаком. В калькуляторе Bybit дополнительно показана сумма
USDT в той же строке: сумма VND / курс USDT/VND. Она доступна и без курса USD/RUB ЦБ.
Сумма вводится в тысячах VND, включая дробные значения с точкой или запятой;
пустой или некорректный ввод очищает расчёт, а не оставляет старую сумму.

## История

SQLite-файл `currency_tracker.db` находится в каталоге документов приложения.
Таблица `rates` хранит наблюдения с источником, валютной парой и временем записи.
Неизменившееся значение повторно не записывается; новое добавляется без удаления
предыдущего. Дата записи означает момент сохранения изменения, а не последней
успешной проверки источника. Уже существующие записи сохраняются.

Выборка графика включает последнее значение до начала периода. Оно переносится
на левую границу только при построении графика; исходная дата в БД не меняется.
График соединяет точки прямыми отрезками. После последней записи и до конца
периода линия продолжается по последнему известному значению.
Расчётные пары пересчитываются при изменении любого из двух исходных курсов.
До первой известной записи значения не дорисовываются. История накапливается
локально: приложение не скачивает архив и не собирает курсы в фоне.

## Сертификат Т-Банка

API использует Russian Trusted Root CA, который может отсутствовать в системном
хранилище Android. Корневой сертификат поставляется с приложением и добавляется
в отдельный HTTP-клиент только для `https://www.tbank.ru:443`. Проверка цепочки,
имени сервера и срока действия остаётся включённой; редиректы отключены.
Системное хранилище устройства не изменяется.

Источник, отпечаток и порядок замены: [assets/certificates/README.md](assets/certificates/README.md).
После изменения сертификата требуется пересборка приложения.

## Разработка и проверки

Требуется Flutter с Dart, совместимым с ограничением SDK в `pubspec.yaml`.

```sh
flutter pub get
flutter run
flutter analyze
flutter test
flutter build apk --debug
```

Тесты проверяют независимое обновление источников, частичные данные, старые курсы
на графике, расчётные пары, SQLite и обработку ошибок API. Они не требуют сети.
Дополнительная проверка реального API новым TLS-клиентом, без записи в БД:

```sh
dart run tool/check_tbank_tls.dart
```
